# 💻 Calculadora Ágil de Hardware

Este proyecto es una aplicación desarrollada en Java para identificar cuellos de botella entre Procesadores (CPU) y Tarjetas Gráficas (GPU), aplicando principios de Clean Code y metodologías ágiles.

## 🚀 Características Principales
* **Manejo de Excepciones Robusto:** Implementación de bloques `try/catch` y excepciones personalizadas (`HardwareException`) para evitar cierres inesperados.
* **Código Limpio (Clean Code):** Separación de responsabilidades (SRP). La lógica matemática compleja ha sido extraída a métodos privados independientes.
* **Interfaz Interactiva:** Menú en consola validado contra entradas vacías o incorrectas.
* **Refactorización Asistida:** Código optimizado utilizando herramientas de IA generativa.
